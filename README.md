## 数据点

| 字段名称 | 说明 |
|------------|-------------|
| `url` | 数据集条目的 URL。 |
| `profile_url` | 个人的 LinkedIn 个人资料 URL。 |
| `linkedin_num_id` | LinkedIn 个人资料的唯一数字标识符。 |
| `avatar` | 与 LinkedIn 账户关联的个人资料图片 URL。 |
| `profile_name` | 个人在其 LinkedIn 个人资料中列出的全名。 |

| `profile_location` | 个人在其 LinkedIn 个人资料中显示的当前位置。 |
| `profile_connections` | 个人在 LinkedIn 上的大致人脉数量。 |
| `profile_country_code` | 表示个人所在国家/地区的 ISO 代码。 |
| `profile_education_full` | 个人的详细教育经历。 |
| `profile_last_education` | 个人最近获得的学历。 |
| `profile_experience_full` | 个人的完整工作经历详情。 |
| `profile_last_experience` | 个人最近任职的职位和公司。 |
| `profile_followers` | 个人在 LinkedIn 上的关注者数量。 |
| `profile_linkedin_id` | 个人的 LinkedIn ID 字符串。 |
| `profile_current_position` | 个人当前的工作职位。 |
| `profile_current_title` | 个人当前担任的职务。 |
| `profile_activity` | 个人最近在 LinkedIn 上进行的活动。 |
| `profile_posts` | 个人在 LinkedIn 上发布的帖子。 |
| `profile_about` | 个人 LinkedIn 个人资料的摘要部分。 |
| `profile_courses` | 个人修读的课程。 |
| `profile_volunteer_experience` | 个人的志愿工作经历。 |
| `profile_languages` | 个人使用的语言。 |
| `profile_publications` | 个人撰写的出版物。 |
| `profile_recommendations` | 个人收到或给出的推荐。 |
| `profile_recommendations_count` | 与个人相关的推荐总数。 |
| `profile_organizations` | 个人目前或曾经加入的组织。 |
| `profile_projects` | 个人参与的项目。 |
| `company_name` | 个人目前或曾经任职的公司名称。 |
| `company_id` | 公司在数据集中的唯一标识符。 |
| `company_linkedin_url` | 公司的 LinkedIn URL。 |
| `company_size` | 按员工人数计算的公司规模。 |
| `company_country_code` | 表示公司总部所在国家/地区的 ISO 代码。 |
| `company_description` | 公司业务活动的说明。 |
| `company_other_employees` | LinkedIn 上列出的同一公司的其他员工数量。 |
| `employees_in_linkedin` | LinkedIn 上列出的该公司员工总数。 |
| `company_linkedin_followers` | 公司在 LinkedIn 上的关注者数量。 |
| `company_locations` | 公司办公地点列表。 |
| `company_founded_year` | 公司的成立年份。 |
| `company_headquarters` | 公司总部所在地。 |
| `company_categories` | 公司所属的行业类别。 |
| `company_logo` | 公司徽标的 URL。 |
| `company_slogan` | 公司使用的宣传语或标语。 |
| `company_specialties` | 公司的专业领域和专长。 |
| `company_updates` | 公司的最新动态或新闻。 |
| `company_website` | 公司的官方网站。 |
| `company_type` | 公司类型，例如上市公司、私营企业或非营利组织。 |
| `company_clean_domain` | 公司网站的标准化域名。 |
| `company_revenue_usd` | 公司的预估美元营收。 |
| `company_total_funding` | 公司获得的融资总额。 |
| `company_total_employees` | 公司在职员工总数。 |
| `company_stock_symbol` | 公司的股票市场代码（如已上市）。 |
| `company_is_non_profit` | 用于标识公司是否为非营利组织的指标。 |
| `company_parent_company` | 母公司名称（如适用）。 |
| `profile_bio_links` | 个人资料简介部分中包含的链接。 |


## 使用场景

### 1. 人力资源分析
通过分析员工的教育经历、工作经验和认证来识别技能缺口与培训需求，从而优化人力资源策略。

### 2. 市场调研
通过分析各行业的员工资料开展市场调研，帮助企业了解竞争对手动态和劳动力分布。

### 3. 业务拓展
利用全面的员工和公司数据发掘合作机会，并制定业务扩张策略。
